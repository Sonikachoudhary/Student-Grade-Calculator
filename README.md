# Student Grade Calculator

A simple C++ program that calculates a student's total marks, percentage, grade, and pass/fail result based on marks entered for five subjects.

## Features

- Takes student name as input
- Takes marks for five subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade
- Displays Pass or Fail result
- Validates marks between 0 and 100
## Technologies Used

- C++

## Sample Output

Total Marks: 438  
Percentage: 87.6%  
Grade: B  
Result: Pass
